## Purpose
Enter the savings the user already has in real life, so the fund matches reality before (or without) logging any period. It does not come from any period.

## Entry & exits
- 7.0 → "Số dư ban đầu" button (create mode; only while there is no base savings).
- 7.0 → tap the "Số dư ban đầu" row (edit mode).
- ✕, "Lưu" or "Xóa" → back to 7.0.

## Layout (top → bottom)
1. Title **"Số dư ban đầu"** · ✕.
2. Amount box **"Số tiền"** (amber accent). Must be > 0.
3. **"Lưu"**. Edit mode adds a destructive **"🗑 Xóa"** below.

No date, no period, no toggle (it only adds to the fund).

## Interactions
- **"Xóa" is always allowed** (D52), even if the fund then goes below 0. The R6.4 "never below 0" check does not apply to this sheet (R6.7). Lowering the amount is allowed the same way.
- After deleting, the row disappears from 7.0 and the "Số dư ban đầu" button comes back.
