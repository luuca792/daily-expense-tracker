## Purpose
Record spending that wasn't itemized, with no category and no description.

## Differences from 5.4
- The **"Không DM"** tile is selected.
- The **"Mô tả" field is hidden**, so the layout is: amount → category grid → "Ngày" → buttons.
- Selecting another category brings the "Mô tả" field back, with any text typed earlier kept.

Everything else is as in 5.4.

## Rules
- **R3.1** (untracked entries). It always counts toward Sinh hoạt, the default goal (R2.2, R4; the 6.0 toggle is removed, D47).
