## Purpose
Add a new expense, or edit an existing one.

## Entry & exits
- ＋ on 5.1 with the toggle on Chi tiêu (R5), or tap an expense row (edit mode).
- "Lưu" → saves and closes. "Lưu & thêm tiếp" → saves, keeps the sheet open and resets the amount and description. ✕ → closes without saving.

## Layout (top → bottom)
1. Grab handle · title **"Thêm khoản chi"** (edit mode: **"Sửa khoản chi"**) · ✕.
2. **Amount box** (light teal): label "Số tiền" on the left, a large amount on the right. Numeric keyboard. Math expressions (`100+218`) come later (D61).
3. **"Danh mục"**: a 4-column grid of tiles, each with a pastel icon tile and a label:
   - first **"Sinh hoạt"** (🍜, preselected, D17), then **"Không DM"** (?, dashed);
   - then the period's goals in user order;
   - last **"＋ Mục tiêu mới"**, which creates a goal (opens 5.6 in create mode, then returns with it selected).
   - The selected tile gets a teal ring and a light-teal background.
4. **"Mô tả"**: text input. Hidden when "Không DM" is selected (→ 5.5).
5. **"Ngày"**: date picker, "📅 dd/MM/yyyy ▾". Only dates inside the period can be picked (R3.5).
6. Two buttons: **"Lưu & thêm tiếp"** (outlined) · **"Lưu"** (primary).

Edit mode also has a destructive text action **"Xóa"** (deleting shows an undo toast).

## States & variants
- **5.5** = this sheet with "Không DM" selected.

## Rules
- Defaults (category, date): **R3.2**. Untracked entries: **R3.1**. Dates inside the period only: **R3.5**.
