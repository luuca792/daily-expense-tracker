## Purpose
Track the Sinh hoạt maximum and the period's goals.

## Entry & exits
- The "Mục tiêu" tab in the bottom bar.
- Tap a goal card → 5.6 (edit). ＋ → 5.6 (create mode) (R5).
- Tap the **Sinh hoạt tracker** → 5.6 in Sinh hoạt mode (`#s5-6b`): edit this period's maximum and icon/color; no delete (D47). Its charts are on 5.3.

## Layout (below the shared 5.0 header and summary card)
1. **Sinh hoạt tracker**, the default goal (orange-tinted card): "🍜 Sinh hoạt" · "<spent> / <maximum>" · a bar.
   - Categorized spending is solid orange; the untracked part is a striped segment.
   - When over the maximum, the spent amount turns red (D34).
2. Summary line: "Đã chi **<Σ spent>** / mục tiêu **<Σ targets>**" (goals only, without Sinh hoạt).
3. **Goal cards** in user order (R2.4). Each card has:
   - an icon tile in the category color and the goal name (bold);
   - "<spent> / <target>" on the right;
   - a bar below.
   - **Bar color:** yellow while spent < target, green when spent = target, red when spent > target (D38). No status text (D34).
   - When overspent, the spent amount is red on a light-red pill (D34).
4. **Done goal** (D59, R2.5): the same card, dimmed, with a green "✓" after the name. Sample: Gia đình.

## States & variants
- **No goals:** only the Sinh hoạt tracker and the ＋ button.
- **Done goal:** dimmed card with "✓" (R2.5).

## Rules
- Goal scope, Sinh hoạt and done goals: **R2.1–R2.5**. Calculations and colors: **R4** (goal bar color, over target).
