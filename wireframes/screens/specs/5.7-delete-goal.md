## Purpose
Confirm deleting a goal and show exactly what happens to its entries.

## Entry & exits
- From 5.6 → "🗑 Xóa mục tiêu này". Never for Sinh hoạt, the default goal, which has no delete action (R2.2, D47).
- "Hủy" → back to 5.6.
- "Xóa" → deletes the goal and returns to 5.2, with an undo toast.

## Layout (top → bottom)
1. A round light-red icon containing 🗑.
2. Title **"Xóa mục tiêu “<name>”?"**
3. **Move box:** <goal icon> "**N khoản** (<amount>)" → 🍜 "**Sinh hoạt**". Only the facts, with no explanatory sentence (D25).
4. Buttons: **"Hủy"** (outlined) · **"Xóa"** (filled red).

## Rules
- Entries move to Sinh hoạt, only in this period: **R2.3**, **R2.1**.
