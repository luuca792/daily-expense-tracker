## Purpose
Edit a goal of this period (name, icon/color, target), mark it done, delete it, or create a new one. Also edits the default goal **Sinh hoạt** (its maximum and icon/color), which can't be deleted.

## Entry & exits
- **Edit:** tap a goal card on 5.2.
- **Sinh hoạt:** tap the Sinh hoạt tracker on 5.2 (D47).
- **Create:** ＋ on 5.2 (R5), or "＋ Mục tiêu mới" on 5.4.
- "Lưu" → saves and closes. ✕ → closes. "✓ Hoàn thành mục tiêu" / "↺ Mở lại mục tiêu" → toggles done, saves and closes (R2.5). "🗑 Xóa mục tiêu này" → 5.7.

## Layout, edit mode (top → bottom)
1. Grab handle · title **"Sửa mục tiêu"** · ✕.
2. A large icon tile (category color) next to the field **"Tên danh mục"** (text input).
3. **"Biểu tượng & màu:"** followed by color swatches (and an icon picker).
4. **Amount box:** "Mục tiêu kỳ này" with a large target amount.
5. Info card: "Đã chi trong kỳ" · "<spent> · <n> khoản ›" with a progress bar in the goal bar colors (D38). "›" opens 5.1 filtered to this category (when filters exist).
6. Primary button **"Lưu"**.
7. Outlined green button **"✓ Hoàn thành mục tiêu"**; on a done goal it reads **"↺ Mở lại mục tiêu"** (D59).
8. Destructive text action **"🗑 Xóa mục tiêu này"** (red).

## Layout, Sinh hoạt mode (`#s5-6b`, D47)
Same as edit mode, except:
- The icon tile shows 🍜 and the **"Tên danh mục" field is read-only** ("Sinh hoạt", grey background).
- The amount box is labeled **"Mức tối đa kỳ này"** (the period's Sinh hoạt maximum).
- "Đã chi trong kỳ" includes untracked spending (R4).
- **No "🗑 Xóa mục tiêu này"** action, so 5.7 can't be reached, and no done button (R2.5).

## Layout, create mode
- Title **"Thêm mục tiêu"**. The fields are empty: name, icon/color, target.
- No "Đã chi trong kỳ" card, no done button and no delete action.

## Rules
- Changes apply **only to this period**: **R2.1**. Sinh hoạt is the default goal: it can't be renamed or deleted: **R2.2**. Done goals: **R2.5**.
