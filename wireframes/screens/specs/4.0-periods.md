## Purpose
List all spending periods and create new ones.

## Entry & exits
- From 2.0 → "Ghi chép". Back "‹" → 2.0.
- "＋ Tạo kỳ mới" → 4.1 (create mode).
- Tap a period card → 5.0 for that period, showing the 5.1 tab.

## Layout (top → bottom)
1. Header: "‹ Ghi chép".
2. Primary button **"＋ Tạo kỳ mới"** (full width).
3. **Year groups**, each with a heading row: the year in large bold type + an expand/collapse chevron (▾ when open, ▸ when collapsed).
4. Inside each year, **period cards**:
   - Icon badge (🗓 by default; the period's own icon if set, e.g. ✈️).
   - **Name** (bold).
   - **Dates** in teal: "dd/MM/yyyy → dd/MM/yyyy", or "dd/MM/yyyy → *chưa kết thúc*" when there's no end date.
   - Totals: "+Thu" (green, shown only if > 0) · "−Chi" (rose) · "N khoản".
   - "›" chevron.
   - No progress bar (D29) and no open/closed badge (D31).
5. The **active period**'s card (R7.1; for now always the most recent period) has a teal outline and a filled icon badge (D54, D61).

## Interactions
- Tap a year heading to collapse or expand it.

## States & variants
- **Empty** (no periods): only the "＋ Tạo kỳ mới" button is shown, with no message (D25).

## Rules
- Grouping and order: **R1.1–R1.3**. End-date display: **R1.4**. No constraints between periods: **R1.5**.
