## Purpose
Create a period (name, dates, previous period for copying and carry-over), or edit an existing one.

## Entry & exits
- **Create:** from 4.0 → "＋ Tạo kỳ mới". "Tạo kỳ" → saves and opens 5.0 for the new period. ✕ → closes the sheet.
- **Edit:** from 5.0 header ⋯ → "Sửa kỳ". "Lưu" → saves and closes.

## Layout, create mode (top → bottom)
1. Grab handle · title **"Tạo kỳ mới"** · ✕.
2. **"Tên kỳ"**: text input. Free text with no suggestions (D26).
3. Two fields side by side:
   - **"Ngày bắt đầu"**: date picker, required.
   - **"Ngày kết thúc"**: date picker, not required. It is empty by default, with no placeholder text and no "(optional)" marker (D25).
4. **"Chọn kỳ trước đó"**: dropdown of the existing periods, with **"Không chọn"** as the last option. The default is the nearest period (R1.6). It copies the goals and the Sinh hoạt maximum; with "Không chọn" the maximum comes from 6.0 (D62).
5. **Carry-over row** (green): "↩️ Còn lại từ tháng trước" on the left and the amount on the right (e.g. "+10.255"). It updates when the selection changes. A negative leftover shows "−" (D60). Hidden when the leftover is 0 or "Không chọn" is selected.
6. Primary button **"Tạo kỳ"**.

## Layout, edit mode
- The title is **"Sửa kỳ"**, and the fields are prefilled.
- **No "Chọn kỳ trước đó" and no carry-over row:** copying happens only at creation (R1.6).
- The primary button is **"Lưu"**, with a destructive text action **"Xóa kỳ"** below it (confirmation + undo toast, D61).

## Interactions
- Validation: the name must not be empty, and the end date must not be before the start date (R1.5). In edit mode, the dates can't exclude existing entries (R3.5, D62). Errors appear next to the field.
- With no periods at all, the selector and the carry-over row are hidden (R1.6).

## Rules
- Copy source and default: **R1.6**. Carry-over entry: **R1.8**. Name: **R1.7**.
