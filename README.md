# Sổ chi tiêu: expense tracker

An installable web app (PWA, Vietnamese UI) that replaces a personal Excel spending workbook. It works offline; data stays only on the user's device; nothing is stored on the server.

| Folder / file | What it holds | Status |
|---|---|---|
| `plan.md` | The original project brief | Input |
| `references/` | The Excel workbook the use cases were derived from (personal data, don't copy from it) | Input |
| [`wireframes/`](wireframes/README.md) | **Design phase:** use cases, UX docs, wireframes, screen registry, logic rules, decisions, open questions | Active |
| [`prototype/`](prototype/README.md) | **Prototype phase:** a lightweight clickable draft that runs locally so the product experience can be tested | Planned |
| [`implementation/`](implementation/README.md) | **Implementation phase:** planning and building the real product | Built, ready to deploy (2026-10-08) |
| `CLAUDE.md` | Hand-off notes for Claude Code sessions | — |

**Flow between phases:** wireframes (design decisions) → prototype (try the experience, give feedback) → implementation (build it properly). Decisions and rules made in `wireframes/` stay the source of truth for the later phases.
